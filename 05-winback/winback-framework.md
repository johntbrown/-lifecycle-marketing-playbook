# Winback Framework

## Objective

Recover customers by understanding why value broke down and matching the intervention to the actual reason for leaving.

## Start With Diagnosis

A cancellation reason should change the treatment.

Common categories include:

- price / affordability
- too much product / cadence mismatch
- lack of perceived efficacy
- habit breakdown
- product fit
- operational frustration
- failed payment / involuntary churn

## Save Hierarchy

Prefer operational and experience fixes before discounting:

1. clarify or educate
2. change cadence
3. skip / pause
4. swap product or configuration
5. offer a targeted incentive
6. cancel cleanly and create a future reactivation path

## Winback Principles

- Do not treat every churned customer the same.
- A customer with unused inventory may still like the product.
- A customer who canceled for price should not receive the same message as someone who canceled for efficacy.
- Separate voluntary churn from passive / involuntary churn.
- Measure retained behavior, not only immediate save acceptance.

## Success

Useful outcomes include:

- retained save rate
- reactivation rate
- time to winback
- post-reactivation rebill
- net revenue after incentive cost
- downstream retention after return

# Winback Segmentation Matrix

## Thesis

Winback should be segmented by why the customer left, how long they have been gone, what they previously owned, and what evidence exists that the original problem is now solvable.

## Core Dimensions

### 1. Exit Reason
Examples:
- price
- too much product
- no perceived results
- wrong product
- forgot / inconsistent use
- failed payment
- temporary pause

### 2. Time Since Exit
Examples:
- 0–30 days
- 31–60 days
- 61–90 days
- 90+ days

Recency matters because the original context may still be fresh early on, while older lapsed customers may need a stronger reintroduction.

### 3. Prior Value
Examples:
- one-order customer
- multi-order customer
- high-LTV former subscriber
- prior cross-sell customer

### 4. Product / Need-State
Use prior product ownership and stated goal to determine whether the original product is still the right return path.

## Example Treatments

### Price + Recent Exit
- cadence adjustment
- lower-cost configuration
- targeted return offer

### Product Buildup + Recent Exit
- reduced frequency
- pause / delay
- usage education

### No Results + Later Exit
- expectation reset
- new proof
- outcome-led education
- alternative product if fit changed

### Failed Payment
- payment recovery first
- no unnecessary incentive

### High-LTV Former Subscriber
- personalized return path
- recognition
- concierge-style support when appropriate

## Measurement

Track:
- reactivation
- next successful order
- retained status after reactivation
- repeat churn
- margin after incentive
- time to return

## Principle

The best winback segment is not “all canceled customers.” It is a meaningful combination of reason, recency, prior value, and product fit.

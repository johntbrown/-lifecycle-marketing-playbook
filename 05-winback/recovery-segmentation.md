# Recovery Segmentation

## Thesis

Winback is not one audience. A paused subscriber, a voluntary cancellation, a failed-payment churn, and a lapsed one-time purchaser are different customer states and should not receive the same recovery journey.

## Recovery States

### Paused Subscriber
The relationship is still active, but timing or inventory is wrong.

Best tools:
- resume reminder
- timing reset
- usage / inventory check
- personalized reason to return

### Voluntary Cancellation
The customer explicitly chose to leave.

Best tools:
- reason-based messaging
- product / plan correction
- objection resolution
- proof or education
- targeted return offer if needed

### Failed Payment / Dunning
The intent to stay may still exist.

Best tools:
- payment recovery
- card update
- clear billing communication
- low-friction account access

### Lapsed One-Time Purchaser
The customer did not cancel a subscription. They simply did not repurchase.

Best tools:
- replenishment timing
- product reminder
- problem / benefit reactivation
- personalized recommendation
- subscription upgrade when appropriate

## Solution-Led Winback

Avoid defaulting to discount-first winback.

Start with the reason the customer left:
- usage problem → education
- wrong product → recommendation
- cadence problem → plan adjustment
- value concern → value framing or right-sizing
- poor experience → service recovery

Financial incentives should support the solution, not substitute for one.

## Measurement

Track:
- reactivation rate
- time to reactivation
- next successful order
- 30 / 60 / 90-day retained status
- margin after incentive
- repeat churn

## Principle

The best winback program does not ask, “What offer will bring this customer back?” It asks, “What changed in the customer relationship, and can we solve it?”
